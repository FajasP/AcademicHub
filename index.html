How It Works
Tamper-proof academic credentials powered by Ethereum & IPFS
🏛️ For Universities — Issuing Records
1

Upload Certificate

The admin uploads the student's certificate (PDF/image). It gets stored permanently on IPFS via Pinata, returning a unique content hash (CID).

2

Write to Blockchain

The student's name, major, GPA, and the IPFS CID are written to the AcademicHub smart contract on Ethereum Sepolia. This is permanent and tamper-proof.

3

Gas Paid with Sepolia ETH

The admin's wallet (MetaMask) signs the transaction. Free Sepolia test ETH covers the gas. On mainnet, real ETH would be used.

🔍 For Students & Recruiters — Verifying Records
1

Enter Student ID

Anyone can enter any Student ID on the Verify tab — no wallet, no login required.

2

Blockchain Query

The backend calls getStudentData() on the smart contract. This is a free read — no gas needed.

3

View Academic Record + Certificate

Name, Major, and GPA appear instantly. Three links are shown: Pinata Gateway, native IPFS link, and a fallback gateway — all pointing to the original certificate file.
